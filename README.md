# 智能合同审核工具 · M1 演示

东浩兰生“AI 来赛”竞赛项目 23「智能合同审核工具」的可演示原型（Demo）。

单文件网页，不需要安装任何环境：双击 `index.html`，用浏览器打开即可全屏演示。

## 演示动线

1. 点击右侧「AI 审查意见」任意一条，自动定位到左侧合同对应条款；
2. 点击「采纳建议」，顶部统计与审查报告同步更新；
3. 点击「生成审查报告」，预览并模拟导出 Word / PDF；
4. 点击「重新审查」，演示 AI 复核过程。

## 说明

- 页面中的合同文本、审查意见与判定依据均为演示用模拟数据，未调用真实大模型；
- 设计的真实链路为：规则引擎 + 法务知识库 + 大模型语义复核 + 法务人工确认；
- 本地规则引擎代码见同工作区 `contract-guard` 目录（条款解析、规则比对、自检工具）。

## 发布为可点击的网址（可选）

在 GitHub 仓库的 Settings → Pages 中，将 Source 设为 `Deploy from a branch`，
Branch 选择 `main` 的 `/(root)` 后保存，约 1 分钟后可访问：

```
https://<你的用户名>.github.io/<仓库名>/
```

注意：免费账号的 GitHub Pages 仅对 Public 仓库开放；Private 仓库可作为内部存档，
但页面链接需要登录且有权限的成员才能访问。
